## Your Task

Produce a comprehensive penetration test report in markdown format.

### Report Structure

1. **Executive Summary**
   - Scope of testing
   - Overall risk rating
   - Key findings count by severity
   - Top recommendations

2. **Methodology**
   - Testing approach (white-box, automated agents)
   - Tools used (nmap, subfinder, whatweb, Playwright, source code analysis)
   - Testing timeline

3. **Findings**
   For each confirmed, exploited vulnerability:
   - Title and severity (Critical/High/Medium/Low)
   - CVSS score estimate
   - CWE classification
   - Affected endpoint(s)
   - Description of the vulnerability
   - Proof of Concept (copy-paste ready)
   - Evidence (request/response)
   - Impact assessment
   - Remediation recommendation

4. **Remediation Summary**
   - Prioritized remediation roadmap
   - Quick wins vs long-term fixes
   - Architecture-level recommendations

5. **Appendices**
   - Full endpoint inventory
   - Technology stack details
   - Tool output summaries

### Rules
- ONLY include findings that have working proof-of-concept exploits
- Zero false positives: every finding must have evidence of successful exploitation
- POCs must be copy-paste reproducible
- Sort findings by severity (Critical first)
