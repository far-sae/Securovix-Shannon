## Your Task

Using the browser, systematically explore the target application:

1. **Authentication Flow**: Log in using provided credentials and document the auth flow
2. **Page Discovery**: Navigate through all accessible pages, noting functionality
3. **API Endpoint Mapping**: Intercept and document all API calls (REST, GraphQL, WebSocket)
4. **Form Enumeration**: Find all forms and document their fields, methods, and actions
5. **JavaScript Analysis**: Review client-side code for API endpoints, hidden functionality
6. **Error Handling**: Test error responses for information disclosure
7. **Session Management**: Document cookie attributes, token storage, session behavior

## Focus Areas
- Prioritize pages and endpoints in the "focus" URL list
- Avoid URLs in the "avoid" list
- Pay special attention to admin panels, file upload, and user management

## Output Format

Produce two deliverables:
1. **exploration.md**: Detailed markdown report of all discovered functionality
2. **api-map.json**: Structured JSON of all discovered endpoints with methods, parameters, and auth requirements
