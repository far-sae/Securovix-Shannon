## Your Task

Analyze the application for XSS vulnerabilities through source code review and live testing.

### Source Code Review
1. Find all user input reflection points in templates/views
2. Check output encoding/escaping practices
3. Identify raw HTML rendering (innerHTML, dangerouslySetInnerHTML, v-html, {!! !!})
4. Review CSP headers and their effectiveness
5. Check DOM manipulation patterns for DOM-based XSS

### Live Testing
1. Reflected XSS: Test all input parameters for reflection
2. Stored XSS: Test persistent storage points (comments, profiles, messages)
3. DOM-based XSS: Test client-side URL parsing, hash fragments, postMessage
4. Template injection leading to XSS
5. SVG/XML-based XSS vectors

### For Each Finding
- Identify exact injection point and context (HTML, attribute, JS, URL)
- Determine if CSP blocks execution and potential bypasses
- Create a working payload that demonstrates impact
- Rate severity based on context (admin panel vs public page, stored vs reflected)

## Output Format

1. **analysis.md**: Detailed analysis with severity ratings
2. **exploitation-queue.json**: JSON findings for exploitation phase
