## Your Task

Analyze the application's business workflows for logic flaws that technical scanners miss.

### Analysis Areas

1. **State Skip Attacks**: Can any workflow state be bypassed?
   - Can you jump from "add to cart" directly to "order confirmed" without paying?
   - Can you skip email verification by directly hitting the verified endpoint?

2. **Price / Quantity Manipulation**:
   - Are prices validated server-side or only in the frontend?
   - Can negative quantities be submitted?
   - Can discount codes be stacked or reused?

3. **Race Conditions (TOCTOU)**:
   - Can parallel requests exploit time-of-check-to-time-of-use gaps?
   - Can you redeem a one-time code multiple times via concurrent requests?
   - Can balance checks be bypassed with simultaneous transactions?

4. **Token / Nonce Reuse**:
   - Are password reset tokens invalidated after use?
   - Can email verification tokens be reused?
   - Are CSRF tokens properly rotated?

5. **Privilege Escalation via State**:
   - Can modifying a role parameter in a request elevate privileges?
   - Can signing up with a special email domain grant admin access?
   - Can mass assignment attacks set admin flags?

6. **Workflow Bypass**:
   - Can required approval steps be skipped?
   - Can moderation be bypassed by direct API calls?

### For Each Finding
- Document the exact workflow being exploited
- Provide the HTTP request(s) that demonstrate the flaw
- Explain the business impact in monetary or access terms
- Rate severity based on business impact, not technical sophistication

## Output Format

1. **analysis.md**: Detailed analysis with business impact
2. **exploitation-queue.json**: Structured findings for exploitation phase
