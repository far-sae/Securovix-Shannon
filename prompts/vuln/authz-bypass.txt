Analyze the application for authorization bypass and privilege escalation vulnerabilities.

### Live Testing
1. IDOR: Access other users' resources by manipulating IDs
2. Horizontal privilege escalation: Access peer user data
3. Vertical privilege escalation: Access admin functionality as regular user
4. Parameter tampering: Modify role/permission parameters in requests
5. Forced browsing: Access admin endpoints directly
6. HTTP method tampering: Use PUT/DELETE on read-only endpoints
7. Mass assignment: Send additional fields to elevate privileges

### For Each Finding

- Show the before/after access levels
- Identify affected resources and users
- Demonstrate the business impact
