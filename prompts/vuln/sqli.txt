## Your Task

Analyze the application for SQL injection vulnerabilities by combining source code review with live testing.

### Source Code Review
1. Find all database query construction points
2. Identify raw SQL queries vs parameterized/prepared statements
3. Look for string concatenation or interpolation in queries
4. Check ORM misuse (raw queries, unsafe find conditions)
5. Review stored procedures and dynamic SQL

### Live Testing
Using the browser, test identified injection points:
1. Classic SQL injection (single quotes, UNION-based)
2. Blind SQL injection (boolean-based, time-based)
3. Second-order SQL injection
4. NoSQL injection if applicable (MongoDB, etc.)
5. ORM injection patterns

### For Each Finding
- Identify the exact vulnerable endpoint and parameter
- Determine the database type and version if possible
- Assess the impact (data exfiltration, auth bypass, RCE)
- Create a minimal proof-of-concept payload

## Output Format

1. **analysis.md**: Detailed markdown analysis of each finding with severity rating

```json
    }
  ]
}
```
